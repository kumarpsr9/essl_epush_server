ERP sync

The college ERP can send student details here whenever they change. Students are matched on roll number. New roll numbers are added, and for existing students only the fields the ERP sends are changed.

Webhook address

URL
POST
Header
Authorization: Bearer <key>
Body
Content-Type: application/json

Give the ERP team this address and a key from below. The address must be reachable from the ERP server: use the API's LAN or public address if this page is open on localhost.

Keys

NameKeyLast usedActions
Each key shows once, when it's created. Revoke a key straight away if it leaks, then create a new one.

What the ERP sends

codeRequiredRoll number. Must match the student's user id on the gate device.
nameFull name. Needed to add a new student.
genderMale or Female (M / F also work). Needed to add a new student.
campusWhere the student studies.Saved in WorkPlace
blockHostel block.Saved in C1
roomRoom number.Saved in C2
bedBed number. One student per bed.Saved in C3
phone10–15 digits.
  • Leave a field out to keep its current value. Send "" or null to clear it.
  • Up to 2,000 students per request, applied in order. One bad record doesn't stop the others.
  • To swap two students' beds, clear one bed first in the same request.

Status 200 means the request was processed: check failed and errors for records that weren't saved. 401 means the key is missing, wrong or revoked.
